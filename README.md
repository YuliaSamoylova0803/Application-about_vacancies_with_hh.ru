## Приложение "Поиск вакансий на hh.py"

+ Приложение, которое будет получать информацию о вакансиях с платформы hh.ru в России, сохранять ее в файл и позволять удобно работать с ней: добавлять, фильтровать, удалять.

## Используются следующие зависимости:

Следует установить:
- poetry init
- poetry add pytest
- poetry add pytest-cov
- poetry add requests 
- poetry add --group lint flake8 black mypy isort


## Использование:
- Реализован абстрактный класс Parser, родительский класс для класса HeadHunterAPI
- Для поиска вакансий написан метод load_vacancies
- Добавлен класс Vacancy для работы с одной вакансией
- Написан абстрактный класс Saver для сохранения информации с сайта
- Реализован наследуемый от Saver класс JSONSaver для получения данных из файла
